# Ashen Hollow — Unity version (code only)

This folder holds the Unity project's code: the game scripts (`Scripts/`), the editor test menu (`Editor/`),
the shaders (`Shaders/`) and the game data tables (`Resources/AH/Data/`). Copy them into
`Assets/AshenHollow/` of the Unity project.

The models, area meshes, textures, sounds and icons are not in the repository: they are large, and some come
from Unity Asset Store packs whose licence allows them inside the game but not as loose files in a public
repository. They stay in the Unity project on the PC. See `README.md` for what is in the game and the credits.
